# BEENOUS
BEENOUS é um sistema de monitoramento e gestão inteligente de energia com priorização que funcionará com a integração de um firmware do Arduino IDE atraves do esp32 que funcionará elém de cérebro do projecto também como um servidor WEB para permitir a interação entre o dashboard WEB e o Sistema de gestão.
O BEENOUS é também o meu Trabalho de Conclusão de Curso [TCC], ele que me dará o título de técnico médio de Informática. É um prazer desenvolver o BEENOUS por esteserá o meu selo e legado, obrigado.
